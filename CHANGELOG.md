# История изменений

## v6.7.0

Первый выпуск на GitHub для существующей версии 6.7.0.

- Архивы для Linux x86-64, macOS Apple Silicon и Windows x86-64 содержат бинарник, лаунчер и дерево файлов, которое требуется проверке целостности при запуске.
- Запуски CI проверяют форматирование, Clippy, хеши исходников и тесты на трёх ОС.
- README описывает архитектуру, показывает пародийный рейтинг и ссылается на воспроизводимый бенчмарк времени запуска и размера исполняемого файла.
